# 弹性打卡助手 (WeChat Mini Program)

一个专为**弹性工作制**与**加班工时记录**设计的微信小程序。支持自由弹性上下班、自动扣除午休时长、智能推算预计下班时间，并精准统计从 19:00 起算的晚间加班时长。

---

## ✨ 核心考勤规则

- **弹性上班**：基准时间 `08:30`，前后各弹性半小时（`08:00 ~ 09:00`）。
  - `08:00 ~ 09:00` 期间打卡判定为正常弹性出勤；
  - 早于 `08:00` 打卡自 08:00 起计满 7.5 小时工时（最早预计 17:30 下班）；
  - 晚于 `09:00` 标记为迟到，并提示迟到分钟数。
- **午休扣除**：中午 `11:40 ~ 13:40` 为休息时间（共 2 小时），系统计算实际出勤工时时**自动扣除**，不计入在岗工作时长。
- **弹性下班推算**：按**每日 7.5 小时标准工时**动态推算下班时间（打卡时间 + 9.5 小时在岗跨度）：
  - `08:00` 打卡 → 预计 `17:30` 下班；
  - `08:15` 打卡 → 预计 `17:45` 下班；
  - `08:30` 打卡 → 预计 `18:00` 下班；
  - `09:00` 打卡 → 预计 `18:30` 下班。
- **晚间加班统计（修正版）**：
  - **1. 周一到周五工作日**：到了满 7.5 小时工时的下班时间后，**休息一个小时才开始计算加班时长**。
    - 休息的一个小时内（如 18:00 ~ 19:00 或 17:30 ~ 18:30）不计入加班；
    - 超过下班+1小时后的在岗时间全额计入加班（例如 08:30 上班预计 18:00 下班，休息至 19:00 起算加班，20:30 下班记录加班 `1小时30分钟`；08:15 上班预计 17:45 下班，休息至 18:45 起算加班，20:15 下班记录加班 `1小时30分钟`）。
  - **2. 周六周日周末**：全天出勤均计为加班，且**把中午（11:40~13:40）及晚上的休息时间都全额计入加班时长**（无任何扣减，按打卡全跨度计算）。
    - 例如周六 09:00 打卡上班、18:00 打卡下班，中午午休计入，记录加班 `9小时0分钟`；
    - 周日 08:30 打卡上班、20:30 打卡下班，中午及晚餐休息均计入，记录加班 `12小时0分钟`。

## 📱 功能特性

1. **今日打卡 (`pages/index/index`)**
   - 动态数字时钟（秒级精准刷新，显示日期、星期与出勤状态）。
   - 智能打卡按钮（上班打卡 / 下班打卡 / 晚间加班更新打卡，支持防早退提醒与触感震动反馈）。
   - 实时在岗追踪（上班后实时显示已在岗工作时长及距离预计下班倒计时，满工时自动标记达标）。
   - 考勤指标四宫格（上班时间及状态、预计下班点、实际下班点、19:00起计加班时长高亮）。
   - 规则时间轴与展开说明。
   - 今日补卡、修改打卡时间及添加备注（如调休、外勤）。

2. **考勤明细与报表 (`pages/records/records`)**
   - 月份选择器与当月考勤汇总（出勤天数、累计工时、**累计加班总时长**、迟到/早退次数）。
   - **日历视图**：以月历展示每日考勤状态圆点与加班时长角标（如 `+1.5h`），点击日期即可查看与编辑单日详情。
   - **列表视图**：按时间倒序展示每日详细打卡数据。
   - 补卡与修改功能：支持对任意历史日期进行考勤补录或删除。
   - **报表导出三合一**：
     - ✉ **一键发邮箱**：全月考勤明细与数据恢复备份直发个人邮箱，永久保存不丢失；
     - 📊 **导出 Excel (CSV)**：生成带 UTF-8 BOM 的标准表格，微信直接打开或发送；
     - 📋 **复制明细文本**：排版清晰的纯文本直接复制到剪贴板。

3. **规则设置与邮箱云备份 (`pages/settings/settings`)**
   - **免费邮箱云备份**：零服务器与免订阅费用，配置邮箱后一键直达，数据永久保存防丢失。
   - 考勤规则个性化设置（可调整上下班基准时间、弹性幅度、午休起止时间、工作日下班休息时长）。
   - 恢复默认预设规则。
   - 导入演示示例数据（一键生成包含工作日休息1h起算加班、周六日全额加班的示例）。
   - 数据备份（导出 JSON）与清空数据。

## 📬 邮箱备份配置与云函数部署

本项目支持将全月考勤汇总、每日打卡清单与 Excel 附件直接发送至您的个人邮箱（如 QQ 邮箱、163 邮箱或工作邮箱），**完全免费，数据私密保存在本地**。

### 1. 部署 `sendMail` 云函数
1. 在 **微信开发者工具** 中打开本项目；
2. 展开左侧文件树，找到 `cloudfunctions/sendMail` 目录；
3. 右键点击 `sendMail` 文件夹，选择 **「上传并部署：云端安装依赖」**；
4. 等待 5 ~ 10 秒提示部署成功即可。

### 2. 获取发件邮箱 SMTP 授权码（以 QQ 邮箱为例）
1. 电脑端浏览器登录 QQ 邮箱（[mail.qq.com](https://mail.qq.com)）；
2. 点击顶部 **「设置」** -> **「账户」**；
3. 向下滚动找到 **「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」**；
4. 开启 **「POP3/SMTP服务」**，按提示用手机发送一条验证短信；
5. 屏幕上会显示一串 **16 位英文授权码**（保存备用）。

### 3. 在小程序中保存设置
1. 打开小程序，点击底部 **「设置」** 标签；
2. 在 **「邮箱云端自动备份」** 卡片中点击 **「配置收发邮箱」**；
3. 填入您的：
   - **发件邮箱账号**（如：`123456@qq.com`）
   - **SMTP 授权码**（上面获取的 16 位授权码）
   - **接收邮箱地址**（可点击「同发件邮箱」，发给自己）
4. 点击 **「保存到本地」**。
5. 之后点击 **「✉ 立即发送本月考勤报表到邮箱」**，精美的 HTML 报表和 Excel (CSV) 附件就会自动投递进您的收件箱！

## 🚀 运行与调试

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开微信开发者工具，选择 **导入项目**。
3. 选择目录 `D:\codes\ClockIn`。
4. AppID 选择自己的小程序 AppID 并开通云开发环境。
5. 导入后即可直接在模拟器中预览、打卡、调试与一键发信。
